# Die Frage nach dem Fehler

**Fehler- und Fragekultur im inklusiven Unterricht** · Konzept und Werkzeuge für die Sekundarstufe I
*Fehler, nach Fragen, nachfragen.*

Ein Le.pApP-Projekt von P. Weins. Konzept & Design: P. Weins · realisiert mit Claude (Anthropic).

**Alle Le.pApP-Werkzeuge:** https://lepapp-inklusiv.de/

## Inhalt

| Seite | Wofür |
|---|---|
| [Konzeptseite](https://peterweins.github.io/die-frage-nach-dem-fehler/) | Das Konzept interaktiv: Grundlagen, Leitsätze, Kompass, zwölf Bausteine, Frageformen, inklusive Zugänge |
| [Stationen-Tool](https://peterweins.github.io/die-frage-nach-dem-fehler/stationen/) | Kompass, Bausteine, Sprache und Frageformen, Fragenspeicher, Beobachten; Einstieg für Lehrkräfte und für die Klasse |
| [Fragezeichen-Reise](https://peterweins.github.io/die-frage-nach-dem-fehler/reise/) | Der spielerische Einstieg für die Klasse: fünf Orte, weiter geht es nur mit einer eigenen Frage |
| [Präsentation](https://peterweins.github.io/die-frage-nach-dem-fehler/praesentation/) | Künstlerische Präsentation für Fachpublikum, mit Musik „Flock“ (© 2007 P. Weins) |
| [Druckvorlagen (PDF)](material/druckvorlagen.pdf) | Signalkarten, Fragewort-Karten, Fehler-Logbuch, Kompass, Ruhe-Fragen-Karten, Frageformen |
